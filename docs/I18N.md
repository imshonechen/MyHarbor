# MyHarbor 多语言支持说明

## 概述

MyHarbor 现已支持多语言功能，默认语言为**中文（简体）**，同时支持**英文**。用户可以在管理后台自由切换语言。

## 已实现的功能

### 1. 多语言配置

- **默认语言**：中文（zh-CN）
- **支持语言**：中文、英文
- **语言持久化**：用户选择的语言会保存在浏览器的 localStorage 中，下次访问时自动应用

### 2. 语言文件位置

```
frontend/src/locales/
├── index.js      # i18n 配置文件
├── zh-CN.js      # 中文翻译
└── en.js         # 英文翻译
```

## 使用方法

### 用户端使用

1. **访问前台首页**
   - 默认显示中文界面
   - 所有文本（搜索框、标签、描述等）均为中文

2. **登录管理后台**
   - 登录页面默认显示中文
   - 输入用户名和密码登录

3. **切换语言**
   - 登录后，在左侧边栏底部可以看到语言切换按钮
   - 点击 **"中文"** 或 **"EN"** 按钮即可切换语言
   - 切换后整个后台界面立即更新为所选语言
   - 语言选择会自动保存，下次访问时保持

### 开发者使用

#### 在组件中使用 i18n

```vue
<script setup>
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
</script>

<template>
  <div>
    <!-- 简单文本 -->
    <h1>{{ t('dashboard.title') }}</h1>

    <!-- 带变量的文本 -->
    <p>{{ t('sites.deleteConfirm.message', { name: siteName }) }}</p>

    <!-- 在属性中使用 -->
    <input :placeholder="t('home.searchPlaceholder')" />
  </div>
</template>
```

#### 添加新的翻译

1. 在 `frontend/src/locales/zh-CN.js` 中添加中文翻译：
```javascript
export default {
  myFeature: {
    title: '我的功能',
    description: '这是一个新功能'
  }
}
```

2. 在 `frontend/src/locales/en.js` 中添加英文翻译：
```javascript
export default {
  myFeature: {
    title: 'My Feature',
    description: 'This is a new feature'
  }
}
```

3. 在组件中使用：
```vue
<template>
  <h1>{{ t('myFeature.title') }}</h1>
  <p>{{ t('myFeature.description') }}</p>
</template>
```

#### 编程式切换语言

```javascript
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

// 切换到中文
locale.value = 'zh-CN'

// 切换到英文
locale.value = 'en'

// 保存到 localStorage
localStorage.setItem('locale', locale.value)
```

## 技术实现

### 依赖包
- **vue-i18n**: v11.x（最新稳定版）

### 配置文件
- **frontend/src/locales/index.js**
  - 创建 i18n 实例
  - 配置默认语言为中文
  - 配置回退语言为中文
  - 从 localStorage 读取用户语言偏好

### 集成方式
- 在 `frontend/src/main.js` 中注册 i18n 插件
- 所有组件自动获得 `$t` 和 `useI18n` 访问权限

## 注意事项

1. **语言切换位置**
   - 语言切换按钮位于管理后台左侧边栏底部
   - 前台首页暂不提供语言切换（可根据需要添加）

2. **浏览器兼容性**
   - 使用 localStorage 存储语言偏好
   - 支持所有现代浏览器

3. **默认行为**
   - 首次访问：显示中文
   - 切换语言后：保存选择，下次访问保持
   - 清除浏览器数据后：恢复为中文

4. **后端数据**
   - 用户输入的数据（站点名称、描述等）不会被翻译
   - 仅界面文本支持多语言

## 扩展语言

如需添加更多语言（如日语、韩语等）：

1. 创建新的语言文件：`frontend/src/locales/ja.js`
2. 在 `frontend/src/locales/index.js` 中导入并注册
3. 在 AdminLayout.vue 的语言切换器中添加新按钮

示例：
```javascript
// locales/index.js
import ja from './ja'

const i18n = createI18n({
  messages: {
    'zh-CN': zhCN,
    'en': en,
    'ja': ja  // 添加日语
  }
})
```

## 总结

MyHarbor 现已完全支持中英文双语，默认语言为中文。所有用户界面文本均已国际化，用户可以在管理后台轻松切换语言。系统会记住用户的语言选择，提供流畅的多语言体验。
