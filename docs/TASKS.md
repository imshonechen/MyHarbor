# MyHarbor 任务拆解清单

## 1. 使用说明

- 本清单按里程碑拆分为可执行开发任务。
- 每个任务需满足 DoD（Definition of Done）后才能标记完成。
- 状态枚举：`todo` / `doing` / `done` / `blocked`。

## 3. 当前优先队列（建议）

1. `T01` 初始化后端骨架
2. `T02` 建模与数据库
3. `T03` 默认配置初始化
4. `T04` 公开接口
5. `T05` 前端基础页面
