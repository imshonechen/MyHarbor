# MyHarbor 测试用例文档

## 1. 目标

- 建立从需求到测试的可追踪关系。
- 覆盖主流程、边界条件、异常路径与回归清单。

## 2. 测试范围

- 后端 API：认证、站点管理、状态检测、统计、备份恢复。
- 前端页面：首页展示、后台管理、设置与可视化。
- 非功能：初始化、定时清理、Docker 部署可用性。

## 3. 需求映射

| 需求 | 用例编号 |
|------|------|
| F1 前台展示 | TC-F1-01 ~ TC-F1-08 |
| F2 管理后台 | TC-F2-01 ~ TC-F2-14 |
| F3 凭证恢复 | TC-F3-01 ~ TC-F3-04 |
| F4 状态检测 | TC-F4-01 ~ TC-F4-08 |
| F5 访问统计 | TC-F5-01 ~ TC-F5-06 |
| NF1~NF8 非功能 | TC-NF-01 ~ TC-NF-08 |

## 4. 核心功能用例

### 4.1 前台展示（F1）

| 编号 | 标题 | 前置条件 | 步骤 | 预期结果 |
|------|------|------|------|------|
| TC-F1-01 | 首页加载公开配置 | 已初始化配置 | 打开 `/` | 显示标题、介绍、版权、ICP |
| TC-F1-02 | 仅显示公开站点 | 存在公开和非公开站点 | 打开首页 | 仅公开站点卡片可见 |
| TC-F1-03 | 标签筛选 | 站点带多个标签 | 选择某标签 | 仅匹配标签的站点显示 |
| TC-F1-04 | 名称搜索 | 存在多个站点 | 输入关键词 | 返回名称/简介匹配站点 |
| TC-F1-05 | 点击站点跳转 | 站点可访问 | 点击站点卡片 | 新标签页打开目标 URL |
| TC-F1-06 | 点击记录写入 | 有访问日志接口 | 点击站点卡片 | 生成 `VisitLog(site_id=目标ID)` |
| TC-F1-07 | Logo 缺省头像 | 某站点无 logo | 打开首页 | 显示名称首字母头像 |
| TC-F1-08 | 主题切换 | 浏览器支持 dark mode | 切换主题 | 主题状态变化并持久化 |

### 4.2 管理后台（F2）

| 编号 | 标题 | 前置条件 | 步骤 | 预期结果 |
|------|------|------|------|------|
| TC-F2-01 | 登录成功 | 有有效管理员账号 | 输入正确账号密码登录 | 返回 JWT，进入后台 |
| TC-F2-02 | 登录失败 | 无 | 输入错误密码 | 返回 HTTP `401`（`detail: invalid username or password`） |
| TC-F2-03 | 登录限流 | 同一 IP 连续失败 | 1 分钟内尝试 > 5 次 | 返回 HTTP `429`（带 `Retry-After`，锁定 15 分钟） |
| TC-F2-04 | 站点新增 | 已登录 | 填写表单提交 | 新站点创建成功 |
| TC-F2-05 | URL 校验 | 已登录 | 提交非法 URL | 返回 HTTP `422`（参数校验失败） |
| TC-F2-06 | 站点编辑 | 已有站点 | 修改名称/标签并保存 | 站点字段更新 |
| TC-F2-07 | 站点删除级联 | 站点有日志和统计 | 删除站点 | 关联日志与统计同步删除 |
| TC-F2-08 | 公开状态切换 | 已有站点 | 切换开关 | `is_public` 状态变化 |
| TC-F2-09 | 批量排序 | 多站点 | 拖拽并保存 | 列表按新 `sort_order` 展示 |
| TC-F2-10 | 单站点检测 | 已有站点 | 点击“检测” | 状态更新并写日志 |
| TC-F2-11 | 全量检测 | 已有站点 | 点击“检测全部” | 返回总数/在线/离线 |
| TC-F2-12 | 查看状态图例 | 有近30天日志 | 打开图例 | 色块与状态一致 |
| TC-F2-13 | 修改安全路由码 | 已登录 | 更新 route code | 返回新路径，旧路径失效 |
| TC-F2-14 | 更新系统配置 | 已登录 | 修改标题与间隔 | 新配置立即生效 |

### 4.3 凭证恢复（F3）

| 编号 | 命令 | 预期结果 |
|------|------|------|
| TC-F3-01 | `python manage.py reset-admin` | 管理员账号重置为默认值 |
| TC-F3-02 | `python manage.py show-admin` | 输出当前管理员用户名 |
| TC-F3-03 | `python manage.py show-route` | 输出当前后台安全路由码 |
| TC-F3-04 | `python manage.py set-admin --username u --password p` | 账号密码更新成功 |

### 4.4 状态检测（F4）

| 编号 | 标题 | 步骤 | 预期结果 |
|------|------|------|------|
| TC-F4-01 | 2xx 判定在线 | 检测返回 200 | 状态为 `online` |
| TC-F4-02 | 3xx 判定在线 | 检测返回 301 | 状态为 `online` |
| TC-F4-03 | 4xx 判定在线 | 检测返回 404 | 状态为 `online` |
| TC-F4-04 | 5xx 判定离线 | 检测返回 500 | 状态为 `offline` |
| TC-F4-05 | 超时判定离线 | 模拟超时 >5 秒 | 状态为 `offline` |
| TC-F4-06 | 未检测默认 unknown | 新增站点未检测 | 状态为 `unknown` |
| TC-F4-07 | 日志写入 | 触发检测 | 新增 `SiteStatusLog` |
| TC-F4-08 | 30天清理 | 执行清理任务 | 仅保留近30天日志 |

### 4.5 访问统计（F5）

| 编号 | 标题 | 步骤 | 预期结果 |
|------|------|------|------|
| TC-F5-01 | 首页访问记录 | 访问首页 | 新增 `VisitLog(site_id=null)` |
| TC-F5-02 | 站点点击记录 | 点击站点卡片 | 新增对应 `VisitLog(site_id)` |
| TC-F5-03 | 日聚合 | 触发每日聚合任务 | 生成 `VisitStats` |
| TC-F5-04 | 概览统计 | 调用 `/stats/overview` | 返回日/月/年/总计 |
| TC-F5-05 | 排行统计 | 调用 `/stats/sites` | 返回按点击排序结果 |
| TC-F5-06 | 90天清理 | 执行清理任务 | 仅保留近90天 VisitLog |

## 5. 非功能测试

| 编号 | 项目 | 验证点 |
|------|------|------|
| TC-NF-01 | SQLite 持久化 | 容器重启后数据仍在 |
| TC-NF-02 | 首次启动初始化 | 自动建表并写默认配置 |
| TC-NF-03 | 静态托管 | 前端 dist 由 FastAPI 正常提供 |
| TC-NF-04 | Docker Compose | 一键启动可访问 |
| TC-NF-05 | 环境变量覆盖 | 端口/DB 路径可覆盖默认值 |
| TC-NF-06 | 检测超时 | 单次请求超时受控在 5 秒 |
| TC-NF-07 | CLI 脚本 | 凭证恢复命令可执行 |
| TC-NF-08 | 定时清理 | 30 天/90 天策略按计划生效 |

## 6. 回归清单（每次发布前必跑）

1. 登录与鉴权链路（成功、失败、过期、限流）。
2. 站点 CRUD + 公开切换 + 排序。
3. 单站点/全站点状态检测与日志写入。
4. 统计概览、排行、趋势接口。
5. 备份导出与导入（skip/overwrite）。
6. 修改后台路由码后跳转与旧路径失效。
